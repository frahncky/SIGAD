# Manual do Desenvolvedor

## Configuração do Ambiente
- Instale Flutter 3.41.6 e Dart 3.11.4
- Clone o repositório
- Execute `flutter pub get` para instalar dependências

## Padrões de Código
- camelCase para variáveis e funções
- Organização por módulos (ex: lib/screens, lib/services)

## Build/Deploy
- Para gerar APK: `flutter build apk`
- Para rodar local: `flutter run`
