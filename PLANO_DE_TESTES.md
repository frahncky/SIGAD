# Plano de Testes

**Objetivo:** Garantir o funcionamento correto das funcionalidades.

## Casos de Teste
- CT01: Cadastro com dados válidos → Esperado: sucesso

- CT03: Login com credenciais corretas → Esperado: acesso
- CT04: Login com senha errada → Esperado: erro

- Flutter Test
