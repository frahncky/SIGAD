# Casos de Uso / User Stories

## UC01 - Cadastro de Usuário
**Ator:** Usuário
**Descrição:** Usuário preenche dados e realiza cadastro.
**Fluxo Principal:**
1. Usuário acessa tela de cadastro
2. Preenche dados obrigatórios
3. Confirma cadastro
**Critérios de Aceitação:**
- Cadastro realizado com sucesso
- Mensagem de erro em caso de dados inválidos

## UC02 - Login
**Ator:** Usuário
**Descrição:** Usuário faz login com e-mail e senha.
**Fluxo Principal:**
1. Usuário acessa tela de login
2. Informa e-mail e senha
3. Recebe acesso ao app
**Critérios de Aceitação:**
- Login válido concede acesso
- Mensagem de erro em caso de falha
