# Especificação de Requisitos

**Objetivo:** Descrever o propósito e as funcionalidades do aplicativo mobile.

## Funcionalidades
- Cadastro de usuários
- Login/Logout
- Consulta de dados
- Notificações push

## Restrições
- Compatível com Android 8+ e iOS 12+
- Uso de Flutter e Dart

## Critérios de Aceitação
- Usuário consegue cadastrar e acessar o app
- Dados exibidos corretamente após login
